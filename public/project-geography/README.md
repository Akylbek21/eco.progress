# География проектов

Самостоятельный frontend без React и backend. Главная страница подключает `index.html` через iframe с lazy loading. Запускать через HTTP (например, `npm run dev` в корне проекта), а не через file://.

Визуальная версия 2: многослойный зелёно-графитовый фон, тонкая перспективная сетка, металлическая поверхность, подсвеченный нижний контур, световые ореолы городов и короткие анимированные следы на дугах. Для свечения используется одна общая текстура 64×64 без постобработки. Статистика появляется с анимацией чисел. `src/components/home/ProjectGeography.tsx` автоматически подстраивает высоту iframe через ResizeObserver.

- `script.js`: массив `cities` — города, координаты, изображения и данные карточек. Новый город появляется автоматически и соединяется с Астаной; существующие связи редактируются в `connections`.
- `style.css`: цвета в CSS variables, адаптивные размеры и reduced-motion.
- `index.html`: заголовки и общая статистика.
- `data/kazakhstan.geojson`: Natural Earth, масштаб 1:50m, public domain. Это географическая визуализация, не кадастровая граница. Источник: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson
- `vendor/`: Three.js 0.180.0 и OrbitControls, MIT (лицензия рядом). Все зависимости локальные.

Числа проектов, статусы, охват 17 регионов — демонстрационные данные из задания, которые нужно сверить перед публикацией. Изображения показывают направления работы компании, а не виды городов. Кнопка карточки открывает существующую страницу `/cases` со всеми кейсами.

Маркеры доступны с клавиатуры; Escape закрывает карточку и возвращает фокус. На мобильных один палец прокручивает страницу, два управляют ракурсом. При ошибке загрузки или отсутствии WebGL остаются список городов и карточки. Reduced-motion отключает пульсацию, движение и заставку; вне экрана и в фоновой вкладке render loop приостанавливается.

На мобильных после вступления длительностью 2,5 секунды отрисовка происходит только при взаимодействии. Фоновые CSS-анимации также приостанавливаются, когда карта не видна.
